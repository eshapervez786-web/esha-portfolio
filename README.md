## 🚀 Getting Started

### Prerequisites

- A modern web browser
- (Optional) Node.js, if your project uses npm

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/esha-portfolio.git
   ```
2. Go into the project folder
   ```bash
   cd esha-portfolio
   ```
3. Open `index.html` in your browser
   *(or run `npm install` and `npm start` if using a framework)*
